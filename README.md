# 🌍 E-commerce para Agenciamento Turístico

Este repositório é uma **vitrine pública** do projeto desenvolvido com apoio da **FACEPE** (Fundação de Amparo à Ciência e Tecnologia de Pernambuco), onde foi proposto o desenvolvimento de um **comércio eletrônico aplicado ao setor de turismo.**

> Este projeto foi desenvolvido como parte de uma bolsa acadêmica e contou com colaboração em equipe.  
> O repositório original permanece privado por questões de segurança.

---

## ✨ Sobre o projeto

O objetivo foi desenvolver um site de e-commerce para uma **agência de turismo real**, com foco em:

- Praticar conceitos de **desenvolvimento web**
- Simular funcionalidades reais de um site de turismo
- Exibir pacotes de viagem, formas de pagamento e canais de contato
- Criar um layout responsivo para diferentes dispositivos

---

- CSS3
